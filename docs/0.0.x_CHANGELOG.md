# Changelog — 0.0.x シリーズ

evoref Free Edition 0.0.x シリーズの変更履歴。

フォーマットは [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) に準拠し、
バージョニングは [Semantic Versioning](https://semver.org/lang/ja/) に従う。

---

## [0.0.8] - 2026-05-31

### Fixed

- conflict_resolution の priority を realtime から background へ修正
- リランカーを llama.cpp rerank 対応の Qwen3-Reranker-0.6B に変更しメモリ最適化
- 設定>開発タブの「ローカルデータを初期化」ボタン文字色を可読化

### Documentation

- meta_cognitive_plan の二重 timeout の意図をコメントで明記

---
## [0.0.7] - 2026-05-30

### Added

- 設定画面に Develop 専用「開発」タブ (local/ 初期化) を追加
- local/ 初期化ヘルパースクリプト (start-core) を追加
- Develop 専用 local/ リセット API を追加

### Fixed

- long_form の構文エラーコード出力時に警告ステップを surface する
- long_form 生成に総ウォールクロック上限を追加し無限ハングを防ぐ
- Level1 プロンプト進化の fitness 識別力と採用ゲートを是正
- reranker の退化スコア(全候補0.0)を selftest で検知して no-op に倒す
- realtime アシスト呼出の purpose timeout を総ウォールクロック予算として強制
- チャットプロンプトに最新外部データの捏造禁止ガードを追加
- executable_command_synth が合成したコマンドを実行前に検証する
- run_command の非ゼロ終了を成否判定に反映し Windows cp932 出力を是正
- コーディングモードのエディタタブ名を ASCII 内容準拠ファイル名にする

---
## [0.0.6] - 2026-05-29

### Added

- long_form 生成の途中経過をチャットとエディタに逐次表示

### Fixed

- long_form コード生成のフェンス混入を除去しエディタ出力と検証を是正
- プロンプト進化が名前プレフィックスを本文へ焼き込む不具合を修正

---
## [0.0.5] - 2026-05-29

### Changed

- frontend の polling とキャンセル要求を共通化 (Free)
- export writer の Markdown 正規表現を共通定数に集約
- CLI の develop/edition セットアップと時刻整形を共通化
- API の HTTPException 手組みを api_error に集約
- Fact View の走査と agent のエラー判定を共通化
- long-form 2 戦略の重複を strategy_common に集約
- RAG の instruction 解決と内部重複を集約
- RAG embedder/reranker を BaseHTTPClient に統一
- policy.get フォールバックを backend/policy_helpers に集約
- 手動ファイル書込・時刻取得を横断基盤に寄せる

### Fixed

- assist purpose 監査の除外行番号を is_tool_error import 追加分だけ更新
- コーディングモードのエディタ出力で空行除去と見出しからのファイル名推定
- コーディングモード長文生成で output_target を伝播してエディタ出力させる

---
## [0.0.4] - 2026-05-28

### Added

- failure_pattern と RalphExecutor の観測性向上
- content_gen タイムアウト 3 値に交差検証を追加
- ツール判定をアシスト接続時はモード非依存で常時有効化
- エディタタブの CLOSE ボタンを常時表示し未保存時は3択確認

### Changed

- develop レビューで見つかった Free 側の小さな整理 3 件

### Fixed

- harness parser に truncated/malformed JSON 検出と action schema 明示
- ループ quality_gate を緑にする (Toast 視認性 + status version SSOT 統一)
- reactive 層で URL recall プリチェックして fetch_url を取りこぼさないようにする
- ユーザー自身の行動宣言をツール起動と誤判定しない
- evolve×非Develop でのサーバ起動失敗を縮退で回避
- コンテンツ生成の first-token / inter-token タイムアウトを分離
- コーディングモード 出力先未指定時はディスク書込せずエディタへ
- GUI 左下バージョン表記を develop 表示 + エディション前スペース対応

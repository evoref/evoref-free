## [0.0.47] - 2026-08-01

### Fixed

- ファイル書き込みで、本文の代わりに作業の実況文が書き込まれることがある問題を修正
- ツールを実行していないのに「実行したが取得できなかった」と報告することがある問題を修正
- 「今の説明を要約して」で、長文の先頭部分しか要約されない問題を修正
- ディレクトリ一覧で、実在しないファイルが挙げられたり、入れ子の項目が直下の項目として並べられる問題を修正
- 「この会話で最初に送ったメッセージは何か」の問い合わせに誤答する問題を修正
- 長文生成の品質チェックで問題が検出されたターンが、成功として記録される問題を修正
- 環境情報を尋ねていない質問の回答に、測定に関する不要な断り書きが混入する問題を修正
- 「300 文字程度で」のような短い分量指定が長文生成へ回り、指定より大幅に長い出力になる問題を修正

### Changed

- チャット応答の検索処理を高速化。検索の要否を判定するアシスト呼び出しを既定で無効にした
  (判定に約 3.4 秒かかる一方、検索本体は約 21 ミリ秒で、判定が処理そのものより高くついていた)。
  無効時は安全側の「検索する」に倒れるため、取りこぼしは増えない
- 検索結果の品質再判定を、実際に判定結果が変わる範囲に限定して発火回数を削減
- タイムアウト時に結果を使わない用途のアシスト呼び出しを、タイムアウト自動延長の対象外に変更
  (失敗のたびに待ち時間が延びる問題の解消)
- ディレクトリ一覧ツールに階層の深さ指定を追加。出力を打ち切った場合は省略件数を明示するようにした

## [0.0.14] - 2026-06-08

### Added

- long_form に設計仕様/フローチャート/スモークテストの config を追加
- コード生成に設計仕様(contract)ステージと整合ゲートを追加
- RAG統計の DashboardRagStats 型・マッピング拡張と i18n キー追加
- /api/rag/stats に運用フィールド (再構築/作成日時・埋め込みモデル) を追加
- 管理画面のモデル変更を migrate ボタンに統一 (base 用 UI 新設)
- 起動時に component (assist/embed/reranker) の model_state 整合性を検証
- model_paths 追跡キーの config 直書きを 403 で遮断し migrate 専用に統一
- assist 経験記録 closure の配線と base モデル名注入 (factory/app_state)
- 経験記録に base_model/conversation_ended/assist 経験の配線を追加

### Fixed

- ディレクトリ宛 write_file の output_<ts>.txt 捏造を停止
- URL recall が末尾日本語を取り込んだ壊れURLを再生する不具合を修正

## [0.0.13] - 2026-06-06

### Added

- LearningScheduler が base=C/assist=B パラメータを config から読み込む
- Level 2 base=C/assist=B 用の config スキーマと launch フラグを追加
- LearningScheduler が Level 2 bootstrap パラメータを config から読み込む
- Level 2 の再起動耐性スケジュールと初回 full-train 用の config キーを追加
- Level 1 プロンプト変異を assist モデルへ寄せて base 競合を解消
- 長文コード生成の cross-file 整合を強化 (幻覚 import 除去 + ファイル単位検証)
- context_size 解決をランタイム consumer に配線
- context_size を arch プロファイルで設定可能にする

### Changed

- 未使用の scheduler.cvector_scale 属性を削除

### Fixed

- base=C control vector の launch edge case を修正
- Level 2 の version_manager/eval_core 注入と LoRA 不在時パス設定・ループ起動配線
- Level 2 スケジュールを再起動耐性のある常駐ループに再設計
- coding モードの editor 単一ショットで散文を成果物にしない品質ゲート
- meta_cognitive ツールループでテンプレート形式の tool-call を解析
- JSON 応答の max_tokens を引き上げ finish_reason=length 切断を抑制
- LTM ベクトルインデックスを sleep-time とシャットダウンで永続化
- 長文コード生成の壊れた出力対策（dataclass検証・反復切除・未解決エラー提示）
- コーディングモードのLLMタイムアウト連鎖と計画矮小化を解消

## [0.0.12] - 2026-06-04

### Added

- コーディングモードの生成品質を横断的に改善
- ツール結果を assist で query 連動抽出し base の接地負荷を下げる
- gemma4 arch モデルプロファイルを追加
- 暴走 reasoning watchdog を追加 (c_15 Phase 1.5c)
- reasoning (enable_thinking) の UI 切替を廃止 (c_15 Phase 1.5d)
- base 起動経路に server 側 reasoning フラグを配線 (c_15 Phase 1.5b)
- reasoning profile スキーマ (ProfileReasoningConfig) を追加 (c_15 Phase 1.5a)
- capability snapshot を Status API に露出 (c_15 Phase 1)
- assist モデルにも能力プローブを配線 (c_15 Phase 1)
- モデル能力プローブ (c_15 Phase 1) - ベースモデルの実挙動を起動時観測して reasoning 適応

### Fixed

- ローカルデータ初期化を「全停止して終了」へ変更 (自動再起動廃止)
- ツール接地回答の温度を下げ weak base のニュース拒否ムラを抑止
- ツール結果注入に話題再フォーカスを追加し multi-turn 話題混同を抑止
- ツール結果注入に capability assertion を追加しニュース等の拒否を抑止
- fetch_url の本文抽出を改善しボイラープレートを除去
- メモリ抽出で reasoning 思考が STM ノートに焼き込まれる汚染を防止
- プロンプト進化で reasoning 思考が system プロンプトに焼き込まれる汚染を防止
- lfm2moe の client_think_budget を 512→4096 に引き上げ
- URL recall の採点で LFM2 の裸数値応答をパースできず学習が常に skip される不具合を修正

### Documentation

- gemma4 プロファイルに gemma-4-12B (dense) のカバレッジを明記
- 未配線 reasoning フィールドにコード注記を追加

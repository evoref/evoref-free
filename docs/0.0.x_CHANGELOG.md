## [0.0.22] - 2026-06-18

### Added

- staged コーディングを実起動 + 設計フローチャート + 2 段階進捗表示

### Fixed

- 生成物間 from-import の名前欠落を決定論ゲートで捕捉
- staged 単一モジュール生成のスタブ化を招くプロンプト文言を是正

- staged 仕様書 (spec.md) の max_tokens 切断を検知して再生成
- staged コーディングのモジュール間 API ドリフトを抑止
- staged コーディングの起動可能性ゲートを強化 (import only の限界対策)
- プラン/spec 切断の再生成と staged 整合ゲートの可測化 (ログ分析対応 A/C)
- staged コーディングに決定論的整合ゲートを追加 (import-only スモークの限界対策)
- staged テスト工程を決定論的スモーク検証ゲートに再設計 (ソース不可変)
- staged コーディングのコード生成失敗とテストリペアによるコード破壊を修正
- コード計画/spec の JSON truncation を検知して可視化する

- fairness 注入チャンクのスコアを final 最低値へ整合 (スケール混在防止)
